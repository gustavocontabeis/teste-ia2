# Tela Principal da Aplicação

## Descrição
Este projeto implementa uma aplicação desktop simples utilizando Java Swing.

## Estrutura do Projeto
- `src/Main.java`: Ponto de entrada da aplicação.
- `src/MainFrame.java`: Classe que define a janela principal e seu comportamento.

## Como Executar
1. Certifique-se de ter o Java JDK instalado.
2. Compile o código fonte:
   ```bash
   javac src/Main.java src/MainFrame.java
   ```
3. Execute a aplicação:
   ```bash
   java -cp src Main
   ```
