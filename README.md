# Calculadora Simples em Java Swing

## Descrição
Esta é uma calculadora simples com interface gráfica para realizar operações matemáticas básicas como soma, subtração, multiplicação e divisão.

## Requisitos
- Java JDK 8 ou superior
- IDE para executar o código (ex: IntelliJ IDEA, Eclipse)

## Como executar
1. Clone ou baixe o repositório.
2. Compile o arquivo `Calculadora.java`.
3. Execute a classe `Calculadora`.
4. Utilize a interface para realizar operações.

## Funcionalidades
- Somar, subtrair, multiplicar e dividir.
- Botões numéricos de 0 a 9.
- Tratamento para divisão por zero.

## Considerações
A interface é responsiva e intuitiva, permitindo um tempo de resposta inferior a 1 segundo para as operações.
