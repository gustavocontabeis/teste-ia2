# Main Application

## Descrição
Essa aplicação demonstra a estrutura base de uma aplicação Java Swing com uma janela principal, um menu e um frame interno.

## Execução
Para executar a aplicação:
1. Compile os arquivos Java.
2. Execute a classe `MainApplication`.

## Requisitos
- Java JDK deve estar instalado.
- As bibliotecas Swing devem estar disponíveis.
